# Flavors of India – Food Culture 🇮🇳

**Flavors of India** is a beginner-friendly web development project that explores India's diverse food traditions. The website introduces Indian cuisine and lets visitors explore dishes associated with different regions, states, and festivals.

![Flavors of India logo](./logo%20(2).jpeg)

## 🌟 Features

- **Home page** introducing Indian food culture.
- **About section** highlighting the variety of Indian cuisine.
- **Regional cuisine cards** for North, South, East, and West India.
- **Separate regional pages** featuring dishes, festivals, and short descriptions.
- **CSS styling** with hover effects, card layouts, and simple animations.
- **Responsive layout rules** to help the website adapt to different screen sizes.

## 🛠️ Technologies Used

- **HTML5** – page structure and content.
- **CSS3** – colors, layouts, animations, and styling.

## 📁 Project Structure

```text
Food-Culture-of-India/
├── index.html        # Main landing page
├── north.html        # North India food page
├── south.html        # South India food page
├── east.html         # East India food page
├── west.html         # West India food page
├── style.css         # Main page styles
├── state.css         # Styles referenced by the regional pages
├── logo (2).jpeg     # Website logo
├── south.html.jpeg   # South India regional image
└── README.md         # Project documentation
```

Keep any other local images referenced by the HTML files in the project folder too. The regional pages currently link to `state.css`, so make sure that stylesheet is present for their intended styling.

## 🎯 Project Purpose

This project is a practical way to learn and practise HTML and CSS, including links between pages, images, navigation, card layouts, hover effects, and responsive design.
